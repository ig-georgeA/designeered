I'm a design leader with a Ph.D. in Human-Centered Design and 16 years designing platform products for developers and analysts. The work starts in user research and ends in production code, and I've done both ends.

Each platform I built solved the bottleneck the previous one exposed. Modeling real user workflows raised the question of whether they actually worked, so the next step was validating decisions before development. Validated designs still got rebuilt by hand, which led to generating production code from them. Once AI entered that pipeline, the job became designing the constraints that make its output trustworthy.

Model the Behavior

Indigo Studio · 6 yrs

Designers were drawing screens while engineers built systems, so the states, transitions, and edge cases between them weren't in anyone's deliverable. They got discovered in code, usually too late to fix cheaply.

Outcomes

Getting the model right was only step one. You still needed to know if it worked for real users, and most teams had no practical way to find that out before committing to build.

Proving a design worked wasn't enough, because the moment it crossed into engineering, it got rebuilt from scratch, and most of the testing and iteration got lost in that manual handoff.

03

Ship Without Waste

App Builder · 4 yrs

Even after a design was validated, engineers rebuilt it from scratch using the spec as a reference. Every handoff was a retranslation, which meant layout fidelity eroded a little more each time. When AI generation entered the platform, the problem changed, since a non-deterministic model now had to produce output an enterprise design tool could trust.

Outcomes
4frameworks, one source of truth
0layout rework at handoff
10×faster to production than hand-coding
Open case study →

Constraining AI generation inside App Builder's design system gave me a method that wasn't tied to that product. When Reveal needed a UX direction for semantic data modeling in days, not weeks, the method was already proven, so the only new variable was the domain.
